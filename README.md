# Yue Zhang Academic Website

This is a clean academic personal website for GitHub Pages.

## Contents

- Profile photo and contact information
- Curriculum Vitae PDF
- Google Scholar, ResearchGate, X, and Bluesky links
- Research statement
- Education
- Manuscript under review
- Journal publications with PDF links
- Conference presentations
- Honors and awards

## Files To Upload

Upload the full contents of this folder to a GitHub Pages repository named:

```text
your-github-username.github.io
```

Important files and folders:

- `index.html`
- `styles.css`
- `CV_YueZhang.pdf`
- `assets/profile.jpg`
- `papers/`

## Publishing With GitHub Pages

1. Create a GitHub repository named `your-github-username.github.io`.
2. Upload all website files and folders.
3. Go to Settings -> Pages.
4. Publish from the `main` branch.
5. Visit `https://your-github-username.github.io`.

## Notes

- The CV link opens `CV_YueZhang.pdf`.
- Most publication PDF links point to local files in `papers/`.
